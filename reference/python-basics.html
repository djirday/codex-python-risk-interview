Python basics

Только syntax, который уже встречался в уроках. Это справочник, а не новый урок.

Имя и значение

dpd = 30
loan_id = "L001"

= сохраняет значение справа под именем слева. Кавычки отмечают текст; число пишется без кавычек.

Показать значение

print(dpd)

print(...) показывает переданное ему значение. Если внутри указано имя, Python использует сохранённое под ним значение.

Basic value types

dpd = 30                 # int
interest_rate = 0.18     # float
loan_id = "L001"         # str
is_overdue = True        # bool

int — целое число, float — число с дробной частью, str — текст в кавычках, bool — True или False. Кавычки превращают даже запись "30" в текст.

List и dict

dpd_history = [0, 10, 35]
dpd_history[1]            # 10
dpd_history[-1]           # 35

loan = {"segment": "prime", "mob": 6}
loan["mob"]               # 6

list хранит упорядоченные значения; index начинается с 0. dict хранит пары key: value; value выбирают по key.

Control flow и function

if score < 600:
    print("high risk")

for payment in loan["payments"]:
    print(payment["amount"])

def is_bad(dpd):
    return dpd >= 30

Indented block принадлежит if, for или function. return отдаёт result function.

Pandas bridge

import pandas as pd

df = pd.DataFrame(loans)

pd — alias библиотеки pandas. В list of dicts каждый dict становится row, а его keys — columns нового DataFrame.

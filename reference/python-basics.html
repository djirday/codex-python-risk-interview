Python basics

Только syntax, который уже встречался в уроках. Это справочник, а не новый урок.

Имя и значение

dpd = 30
loan_id = "L001"

= сохраняет значение справа под именем слева. Кавычки отмечают текст; число пишется без кавычек.

Показать значение

print(dpd)

print(...) показывает переданное ему значение. Если внутри указано имя, Python использует сохранённое под ним значение.

Basic value types

dpd = 30                 # int
interest_rate = 0.18     # float
loan_id = "L001"         # str
is_overdue = True        # bool

int — целое число, float — число с дробной частью, str — текст в кавычках, bool — True или False. Кавычки превращают даже запись "30" в текст.

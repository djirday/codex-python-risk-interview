# Подтверждено различение basic value types

Учащийся без запуска кода правильно различил `int`, `float`, `str` и `bool` по записи значений: целое число без кавычек и десятичной точки, дробное число с точкой, текст в кавычках и `True` с заглавной буквы без кавычек. Это evidence завершения Lesson 0002 и позволяет перейти к контейнерам `list` и `dict`.

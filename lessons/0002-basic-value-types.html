1 · До → Код → После

Python видит значение и его type

dpd = 30
interest_rate = 0.18
loan_id = "L001"
is_overdue = True

30 — целое число, type int.

0.18 — дробное число, type float.

"L001" — текст, type str.

True — логическое «да», type bool.

Зачем: type определяет допустимые операции. Ставку можно умножать, а loan ID нужен как идентификатор, даже если похож на число.

2 · Главная ловушка

Кавычки меняют type

dpd_number = 30
dpd_text = "30"

30 — int, а "30" — str. В risk data числа иногда приходят как текст — тогда расчёты требуют cleaning.

3 · Да или нет

bool хранит два возможных значения

is_overdue = True
is_restructured = False

True и False пишутся с заглавной буквы и без кавычек. Такой flag читается как короткий вопрос: «кредит просрочен?»

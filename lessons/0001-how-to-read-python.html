Python с абсолютного нуля

Три строки — без страха

Сегодня только одна способность: увидеть имя, значение и команду показать значение. Никаких таблиц и сложных терминов.

Этот урок уже пройден в этом browser

1 · Имя и значение

Сохраняем число под именем

dpd = 30
имяdpd
←
значениечисло 30

Знак = здесь читаем как: «сохрани значение справа под именем слева».

Нажмите на часть строки

Выберите dpd, = или 30.

2 · Текст

Кавычки отмечают текст

loan_id = "L001"

loan_id — имя. "L001" — текстовое значение. Кавычки показывают Python, что внутри находится именно текст; сами кавычки не являются частью loan ID.

loan_id — имя → = — сохранить → "L001" — текст.

Что здесь является текстом?

3 · Показать значение

print(...) показывает результат

dpd = 30
print(dpd)

print — готовая функция Python. Круглые скобки содержат то, что мы просим показать. Здесь внутри имя dpd, поэтому Python находит сохранённое значение и показывает 30.

1 · Dataset и mental model

Один DataFrame, один row grain

import pandas as pd

loans = pd.DataFrame({
    "loan_id": ["L001", "L002", "L003", "L004", "L005"],
    "segment": ["prime", "near_prime", "prime", "near_prime", "prime"],
    "dpd": [0, 35, 10, 65, 40],
    "balance": [10000, 7000, 12000, 5000, 8000],
    "limit": [15000, 8000, 15000, 6000, None]
})

Grain: одна row = один loan на reporting date. Без ясного grain нельзя безопасно считать portfolio metrics.

5 · Derived columns

Vectorized calculation

loans["is_bad"] = loans["dpd"] >= 30
loans["utilization"] = loans["balance"] / loans["limit"]

Pandas применяет operation к aligned values всей Series — explicit for не нужен. is_bad хранит reusable flag, а utilization связывает exposure с limit. Это arithmetic metric, не causal conclusion.

6 · Missing values

Сначала measure, потом policy

loans["limit"].isna().sum()       # 1
loans["utilization"].isna().sum() # 1

isna() отмечает missing values, sum() считает True. Missing limit распространяется в division: для L005 utilization тоже NaN. Не заменяйте limit на zero автоматически — это business assumption и zero создаст проблему division.

7 · Rank the risk view

sort_values и проверка результата

review = (
    loans.loc[loans["is_bad"], ["loan_id", "dpd", "balance"]]
         .sort_values("balance", ascending=False)
)

review.shape           # (3, 3)
review["balance"].sum() # 20000

Parentheses позволяют читать chain по стадиям. Сначала filter, затем sort descending. Итоговая validation проверяет ожидаемые rows и total bad balance; original index может остаться 4, 1, 3 — это labels, не row count.

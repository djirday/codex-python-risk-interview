3 · Decision logic

Operators и if

><>=<===!=andornot

Comparisons дают True или False. and требует оба условия; or — хотя бы одно; not переворачивает boolean.

if loan["risk"]["score"] < 600:
    print("high risk")

Двоеточие открывает block. Четыре пробела indentation показывают, что print принадлежит этому if и выполняется только при true condition. Здесь score равен 642, поэтому текст не появится.

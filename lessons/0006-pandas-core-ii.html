2 · Duplicate diagnostics

Не удалять до понимания причины

loans.duplicated(subset="loan_id", keep=False)
loans.drop_duplicates(subset="loan_id", keep="last")

duplicated(..., keep=False) отмечает все occurrences повторяющегося key. drop_duplicates — уже policy: применять только если известно, почему выбран first или last.

3 · Groupby mental model

Split → apply → combine

segment_balance = (
    loans.groupby("segment", as_index=False)["balance"]
         .sum()
)

Дано для расчёта

prime balances: 10000, 12000, 8000. near_prime balances: 7000, 5000.

groupby("segment") собирает rows в groups, sum() применяется внутри каждой group, а as_index=False оставляет segment обычной column.

Дано: prime = 10000 + 12000 + 8000. Какой total?

Дано: есть только prime и near_prime. Сколько rows в result?

4 · Named aggregation

Несколько portfolio metrics за один pass

summary = loans.groupby("segment", as_index=False).agg(
    loan_count=("loan_id", "nunique"),
    total_balance=("balance", "sum"),
    bad_loans=("is_bad", "sum"),
    bad_rate=("is_bad", "mean")
)

Дано для расчёта

is_bad = dpd >= 30. prime flags: False, False, True. near_prime flags: True, True.

В каждой паре слева задаётся output column, справа — (source_column, aggregation). Для boolean values: sum считает True, mean даёт долю True.

Дано: prime flags = False, False, True. Чему равен bad_loans?

Дано: у prime 1 bad из 3 loans. Какой bad_rate?

Дано: near_prime flags = True, True. Какой bad_rate?

Дано: near_prime balances = 7000 и 5000. Какой total_balance?

5 · Merge with a contract

Добавляем target по segment

Дано

segmentbad_rate
prime0.333
near_prime1.000
segmenttarget_bad_rate
prime0.10
near_prime0.25
report = summary.merge(
    targets,
    on="segment",
    how="left",
    validate="one_to_one",
    indicator=True
)

left сохраняет все summary segments. validate="one_to_one" превращает ожидаемую cardinality в executable check. indicator=True добавляет _merge для проверки matching.

Дано: summary — left table. Какой how сохраняет все её segments?

Дано: в обеих tables segment встречается один раз. Какой validation contract?

Дано: prime есть и в summary, и в targets. Что содержит его _merge?

6 · Portfolio validation

Rows, totals, matches

assert len(report) == len(summary)
assert report["total_balance"].sum() == loans["balance"].sum()
assert report["_merge"].eq("both").all()

Дано для checks

summary totals: prime 30000, near_prime 12000. Source total: 42000. Обе target rows matched.

Validation отвечает на три разных вопроса: не изменился ли row count, сохранился ли денежный total, все ли keys нашли match. Один check не заменяет остальные.

Дано: segment totals 30000 и 12000; source total 42000. Сохранён ли balance?

Дано: после left merge одна row имеет _merge = "left_only". Что это значит?

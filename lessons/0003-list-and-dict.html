1 · List

Порядок значений важен

dpd_history = [0, 10, 35]

Квадратные скобки создают list. Здесь в одном имени хранится DPD клиента за три месяца: сначала 0, затем 10, затем 35.

dpd_history[0]  # 0
dpd_history[2]  # 35

Позиции в Python начинаются с 0. Поэтому первый элемент имеет index 0, а третий — index 2.

Что вернёт dpd_history[1]?

2 · Dict

Значение названо key

loan = {
    "segment": "prime",
    "bad_rate": 0.07
}

Фигурные скобки создают dict. Каждая пара состоит из key: value: например, key "segment" ведёт к value "prime".

loan["segment"]  # "prime"

У dict мы указываем не позицию, а нужный key. Это похоже на одну строку таблицы, где key напоминает название column.

Что вернёт loan["bad_rate"]?

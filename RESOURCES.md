# Python Risk / Portfolio Analytics Resources

## Knowledge

- [pandas: What kind of data does pandas handle?](https://pandas.pydata.org/docs/getting_started/intro_tutorials/01_table_oriented.html)
  Official introduction to `DataFrame`, `Series`, rows and columns. Use for: Block 1 mental model.
- [pandas: 10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html)
  Official compact guide to creation, viewing, selection, missing data, merge and grouping. Use for: Blocks 1–4.
- [Python tutorial: an informal introduction](https://docs.python.org/3/tutorial/introduction.html)
  Official language introduction. Use only for the minimum Python syntax needed to read analytical code.
- [Apache Arrow: Reading and Writing Parquet files](https://arrow.apache.org/docs/python/parquet.html)
  Official PyArrow guide to Parquet I/O and selective reads. Use for: Block 5.
- [DuckDB: Reading and Writing Parquet Files](https://duckdb.org/docs/stable/data/parquet/overview)
  Official guide to SQL over Parquet, filters, projections and multiple files. Use for: Block 5.
- [pyodbc wiki](https://github.com/mkleehammer/pyodbc/wiki)
  Maintainer documentation for Python ODBC connectivity. Use for: Block 6.
- [Microsoft ODBC Driver for SQL Server](https://learn.microsoft.com/en-us/sql/connect/odbc/microsoft-odbc-driver-for-sql-server)
  Official Microsoft driver documentation. Use for: Block 6 architecture, installation and connection prerequisites.
